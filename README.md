# StudyMKD

本地优先的视频学习笔记工具。课程目录可由截图 OCR 生成，每个章节可以记录富文本笔记、重点、视频时间、截图、学习回顾、附件和复习卡片；桌面版还提供专注笔记与专注复习窗口。课程目录、笔记与视频截图可导出为单个 Markdown 文件。

完整的环境准备、启动步骤、数据位置和使用方法见 [使用说明.md](./使用说明.md)。

## 当前可用功能

- 顶部课程菜单支持新建、切换、重命名和删除课程项目；切换后目录、笔记与学习信息同步更新
- 课程名称全角/半角、大小写及多余空格归一化查重，避免创建重复课程
- 遇到同名课程时可使用已有课程，或在二次确认后替换已有课程
- 新建课程时可设置预计完成周期（天、周或月），并在课程进度区域持续显示
- 目录截图上传后自动 OCR，本地中英文模型无需联网，识别结果可在导入前修订
- 目录图片默认增量合并，仅追加新章节并保留已有笔记；替换整个目录需明确选择
- 支持从目录图片识别三层章节结构
- 课程目录支持按章节名称实时搜索，并可筛选全部、未开始、学习中、已完成状态
- 支持一键删除到零章节，仅保留课程文件夹后重新导入或新增
- 章节状态和总体进度
- 每章可设置计划学习时长；点击“学习中”开始倒计时，支持暂停、继续、重置和超时统计
- 全部章节完成后，课程目录显示累计实际学习用时
- 课程学习计划支持每周可用时段、专注/休息节奏、缓冲比例和目标周期
- 自动分析剩余学习量、每周有效时间、预计完成日期、目标偏差并生成最近学习安排
- 预测与章节计划分钟数、完成状态、实际计时和历史学习速度实时联动
- 富文本笔记、荧光重点、列表和引用
- 当前章节笔记支持关键词高亮、上下匹配跳转和键盘搜索操作
- 全局搜索可跨课程匹配章节标题、笔记、标签、截图说明、章节回顾与复习卡片，点击结果直接跳转
- 带语言选择与语法高亮的代码块，并在 Markdown 导出中保留语言围栏
- 视频截图、时间点及说明
- 章节排序（上移/下移）、复制章节、跨课程移动章节
- 目录可按状态筛选，也可按标签筛选章节
- 每个章节可保存单个文件、多个文件或完整项目文件夹，并保留相对路径
- 导入时选择“链接原文件”或“项目托管目录”；不支持文件句柄的环境会禁用链接模式
- 章节文件支持应用内项目浏览与图片、PDF、音视频、文本、代码预览
- 文件预览显示可复制的存储位置，并可将整个章节文件结构保存到用户选择的 Windows 文件夹
- “打开本地文件夹”会同步章节文件到 `data/managed/课程/章节/` 并启动 Windows 资源管理器；文件图标可在资源管理器中选中对应副本
- 删除托管文件时同时清理 IndexedDB 与 `data/managed` 副本；链接模式只移除链接，绝不删除源文件或用户手动导出的副本
- 重命名课程会同步移动应用托管目录；删除课程会清理课程数据和应用托管副本，不删除链接源文件
- 双击截图进入可编辑批注画布，支持画笔、箭头、文字、区域擦除、清空全部、颜色、粗细和撤销重做
- 截图批注编辑器可同时修改截图描述、视频时间和线上地址；截图列表可用系统浏览器打开链接
- Markdown 导出保留截图描述与时间，并将设置了线上地址的图片导出为可点击图片链接
- 重点分类、标签和章节回顾
- 重点、有疑问、待复习、可实践、已掌握等标记同步显示在课程目录
- 当前章节笔记可导出为 `.studymkd-note.json` 制卡素材，并导入 AI 生成的 `.studymkd-cards.json`
- AI 卡片导入前支持逐张预览、勾选、修改问题/答案/标签，并自动跳过已有和文件内重复问题
- AI 卡片导入可选择追加或覆盖当前章节；覆盖模式会用本次勾选结果重建章节卡片
- 右侧只预览前两张复习卡片，支持复选、多选、全选和批量删除；查看更多会打开独立专注复习窗口
- 仓库附带 `studymkd-card-maker` Codex Skill：从笔记识别学习主题，生成正常的知识问题，并可扩展直接相关的准确原理、用途、对比和实践注意点
- 复习卡片的问题与答案可编辑，并支持确认删除
- 点击顶栏“今日复习”进入逐卡复习工作台：显示问题、查看答案、按忘记/困难/掌握评级并自动排期，结束后统计本次结果
- 学习计时自动记录为学习历史；顶栏“学习统计”展示今日/本周/本月/累计用时、最近 12 周热力图和各章节计划与实际用时对比
- 最近 12 周热力图按周一到周日排列，月份仅在进入新月份时显示一次，当前周未来日期不会计入统计
- 本地 IndexedDB 自动保存
- 顶栏“备份”可将全部课程数据（含截图、附件、卡片与计时）导出为单个 JSON 文件，并支持预览后整体替换或合并导入
- 单个 Markdown 文件导出，截图引用应用托管目录中的本机绝对路径
- 导出前自动探测本地桥接：通过 `npm run dev` 启动时同步截图到托管目录并使用 `file:///` 路径；生产静态环境或同步失败时自动把最新批注截图内嵌为 Base64，保证导出文件自包含，并提示内嵌数量
- 截图上传时创建本地托管副本，导出前同步最新批注版本，避免不兼容的 Base64 代码
- 章节回顾、学习信息、复习卡片和章节附件不会加入导出文件
- 粗体、斜体、重点标记、列表、引用和带语言代码块使用统一 Markdown 语法
- 响应式桌面和移动端布局
- Electron Windows 桌面版，支持独立专注笔记小窗、始终置顶和主/小窗实时同步
- 专注小窗可返回并聚焦主窗口；返回时关闭小窗并立即解除当前章节编辑锁
- 专注小窗同章节编辑锁，防止两个窗口同时保存造成内容覆盖
- 独立专注复习窗口按单卡展示问题和答案，并同步忘记、困难、掌握评级结果

## 快速开始

普通用户直接运行 Windows 安装程序：

```text
frontend/release/StudyMKD-0.1.0-Setup.exe
```

安装后的应用不需要 Node.js、npm、C++ 后端或单独安装浏览器。当前安装包未使用商业代码签名证书，Windows 可能显示“未知发布者”；请确认安装包来自本仓库后再继续。

从源码启动桌面开发版：

```powershell
cd frontend
npm install
npm run desktop:dev
```

只启动浏览器开发版：

```powershell
cd frontend
npm install
npm run dev
```

然后打开 `http://127.0.0.1:5173/`。

## Windows 桌面版

运行 `npm run desktop:build` 后，安装程序生成在 `frontend/release/StudyMKD-0.1.0-Setup.exe`。

桌面版数据位置：

- 课程、笔记等 IndexedDB 数据：`%APPDATA%/StudyMKD/`
- 托管截图与章节文件：`Documents/StudyMKD/data/managed/`

浏览器版和桌面版使用不同的本地存储空间。迁移已有课程时，先在浏览器版点击“备份”导出 JSON，再在桌面版“备份”中导入。

## AI 制作复习卡片

1. 在章节“我的笔记”右上角点击“AI 制卡”，导出笔记素材。
2. 把 `.studymkd-note.json` 交给 Codex，并使用 `$studymkd-card-maker` 生成 `.studymkd-cards.json`。
3. Skill 以笔记确定主题，可以扩展直接相关的原理、对比、实践和排错知识；不会生成“笔记里写了什么”这类题目。
4. 回到同一个章节，导入生成文件，逐张勾选并修改问题、答案和标签。
5. 选择“追加”保留已有卡片并跳过同题卡，或选择“覆盖当前”用本次勾选结果重建当前章节卡片。

StudyMKD 会核对文件版本、课程 ID、章节 ID 和笔记内容哈希。笔记在生成卡片后发生变化时，导入界面会提示来源已变化；卡片仍需由用户检查确认后才会写入，不会静默修改数据库。

Skill 的可分发版本位于 `skills/studymkd-card-maker/`。其他电脑可将该目录复制到 `%USERPROFILE%/.codex/skills/studymkd-card-maker/`，然后在新的 Codex 任务中调用 `$studymkd-card-maker`。

## 复习卡片

- 右侧章节信息只预览前两张卡片，避免卡片过多导致页面过高。
- 卡片支持单选、多选、全选、批量删除，以及逐张编辑和删除。
- 点击“查看更多”打开独立专注复习窗口；显示答案后可按忘记、困难、掌握评级。
- 忘记安排为今天再次复习，困难安排到 2 天后，掌握安排到 5 天后。
- 顶栏“今日复习”汇总所有课程中已经到期的卡片。

## 截图与线上地址

双击截图进入批注编辑器，可绘制画笔、箭头和文字，执行区域擦除、清空、撤销和重做。编辑器顶部可同时修改截图描述、视频时间和线上地址。

- 线上地址仅接受 `http://` 或 `https://`；省略协议时自动补为 `https://`。
- 地址可从编辑器或截图列表交给系统默认浏览器打开。
- Markdown 导出保留描述和视频时间；存在地址时，图片本身也会成为可点击链接。

## C++ 后端

后端使用 C++20、Drogon、SQLite、OpenCV 和 Tesseract。当前前端无需后端也可完整运行；安装 Windows C++ 工具链后可切换到本地原生服务。

推荐先安装 Visual Studio Build Tools、CMake 和 vcpkg，然后运行：

```powershell
cd backend
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=C:/path/to/vcpkg/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release
./build/Release/keji_backend.exe
```

本地服务仅监听 `127.0.0.1:8787`。接口约定见 `docs/API.md`。

## 数据与隐私

浏览器版本的数据保存在当前浏览器的 IndexedDB 中；桌面版数据保存在 Electron 的本地用户目录。截图与笔记不会自动上传，目录 OCR 的中文与英文模型随应用在本地提供。

StudyMKD 当前不会直接调用在线 AI。只有当用户主动把导出的 `.studymkd-note.json` 提供给 Codex 时，该章节的笔记素材才会进入 AI 制卡流程；其他课程、截图二进制、附件和完整应用数据库不会包含在制卡素材中。

章节文件有两种存储方式：

- `项目托管目录`：复制文件内容到 IndexedDB，原文件移动后仍可预览和导出。
- `链接原文件`：只保存文件句柄，不复制内容；预览和导出读取原文件。原文件移动、删除或权限失效后链接不可用。此模式需要 File System Access API 支持。
